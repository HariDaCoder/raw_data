# Dữ liệu Excel

- `crawled_posts_20260527_165432_standardized.xlsx`: Dữ liệu bài viết đã crawl và chuẩn hóa.
- `facebook_posts_20260527_163543_standardized.xlsx`: Dữ liệu bài viết Facebook đã chuẩn hóa.
  - Các cột chính: `name`, `address`, `text`, `bio`, `link`, `date`, `images`, `videos`, `keyword`, `source`.

## Giải thích các cột

- `name`: Tên người/nhóm đăng bài hoặc tiêu đề nguồn.
- `address`: Địa chỉ trang, hồ sơ, hoặc nơi xuất bản bài viết.
- `text`: Nội dung chính của bài viết.
- `bio`: Thông tin mô tả thêm về tác giả hoặc trang.
- `link`: Đường dẫn trực tiếp tới bài viết.
- `date`: Ngày đăng bài.
- `images`: Danh sách hoặc số lượng ảnh kèm theo bài viết.
- `videos`: Danh sách hoặc số lượng video kèm theo bài viết.
- `keyword`: Từ khóa hoặc chủ đề liên quan đến bài viết.
- `source`: Nguồn dữ liệu hoặc kênh thu thập.
